# Mars Explorer 3D

create a website about mars, with a homepage that talks generally about mars.Theres a side bar where u can click to open it to a realistic 3D model of mars where u can click on certain points on the model and it will show a futuristic habitat on mars with all necessities for life, a different point will open a small window of text with the characteristics of the habitat.On a different menu item theres a separate realistic 3D model of mars than u can rotate and interact with. Use these photos as reference for how the website should look.use the photos of the habitats i sent you to use for each of the habitats.
